# 醫院碳排計算器

[開啟計算器](https://yht5582-source.github.io/hospital-carbon-calulator/) · [② 比較同規模機構](https://yht5582-source.github.io/hospital-carbon-calulator/#comparison) · [③ 減排建議](https://yht5582-source.github.io/hospital-carbon-calulator/#advice)

供醫院及透析中心試算排放、查看主要排放來源，並依相近的盤查邊界與同儕資料比較排放強度。

## 開始使用

1. 選擇 **全院年度排放** 或 **血液透析服務**。也可先按「選擇示範案例」查看填報方式。
2. 填入盤查年度、活動量及相應排放係數。使用一致的院區或服務邊界與活動期間。空白項目視為未納入，確認活動量為零時可填 0。
3. 全院模式填入同年度實際住院人日，即可使用公開同儕的自動比較。也可依需要填入住院床數、透析床數及同期實際透析次數。按 **帶入北港附醫規模** 可載入可編輯的參考值。
4. 頁面依三步驟呈現：**① 計算碳排量**（總量與來源占比）→ **② 比較同規模機構**（排放強度判讀）→ **③ 減排建議**（優先來源，並依步驟 2 結果顯示回到參考值所需的降幅）。按 **下載試算明細（CSV）** 留存輸入值與結果。

## 計算口徑

| 模式 | 計算方式與輸出 |
| --- | --- |
| 全院年度排放 | 各項活動量乘以排放係數，彙整範疇一、二、三。年度合計以公噸 CO₂e 呈現。填入同年度床數後，可查看年度範疇一＋二每床排放。 |
| 血液透析服務 | 將歸屬於透析的同期排放除以同期完成的透析次數，得到公斤 CO₂e／次。共用製水或空調須先按合理依據分攤。全院用電若已涵蓋透析用電，彙整全院總量時只計一次。 |

**北港附醫規模設定**採 481 張住院床、60 張透析床及每月約 3,000 次透析。若輸入涵蓋 12 個月的活動數據，估計同期透析量約為 36,000 次，約每床每月 50 次。實填的同期透析次數優先使用，估計分母會在畫面及 CSV 標示。床數與服務量用來換算強度，排放量仍需依活動數據及係數計算。[住院床位公告](https://www2.bh.cmu.edu.tw/Announce/CurrentBedAvailability) · [透析床位來源](https://www2.bh.cmu.edu.tw/Department/History?depid=185)

## 同規模比較與減碳建議

- **全院比較**使用範疇一＋二排放強度。可輸入同年度實際住院人日，對照國軍臺中總醫院公開資料，或自填同規模機構的每住院人日／每床每年參考區間。內建值為 2024 年 33.67、2025 年 33.18 公斤 CO₂e／住院人日。系統優先使用同年度數值，較新的年度會標示為跨年度初步參考。[公開來源](https://803.mnd.gov.tw/esg/environmental-sustainability/energy-management/)
- **透析比較**使用同期實際治療次數，對照使用者自填的同規模中心區間。請確認床數、服務量、治療時數及生命週期邊界相近，並核對病人交通的納入方式。公開案例表另外提供林口長庚及國際研究數值供查閱。[林口長庚](https://www.cgmh.org.tw/showroom/News/PressNews/260915002) · [歐洲四家透析中心研究](https://pubmed.ncbi.nlm.nih.gov/42610222/)
- **全院自動判讀**在年度、範疇一＋二及實際住院人日填妥後，即時顯示相對位置。若有空白項目，補填或核對空白項目皆不適用後勾選確認。自填區間仍須確認口徑。畫面依 ISO 14064-1 與 GHG Protocol 提供基本填報檢核，正式符合性須依完整盤查及查證確認。
- **減排建議**依已計入的排放量排序，最多顯示三項來源。步驟 2 判讀為高於參考時，另顯示強度需降低多少百分比才能回到參考值或區間上限。可試算單一項目下降 5%、10%、20% 或 30% 時的減量，假設其他排放及服務量維持相同。

## 部署與資料處理

網站入口為儲存庫根目錄的 [`index.html`](./index.html)。推送至 `main` 後，由此儲存庫既有的 GitHub Pages 流程部署。也可下載 `index.html` 並直接以瀏覽器開啟。

試算、比較及 CSV 產生均在瀏覽器內執行。重新整理會清除輸入，請在離開頁面前自行匯出需留存的資料。正式盤查、申報或查證須依適用規範確認邊界、排放係數與資料品質。
